# 国际化（i18n）

## 设计选择

**不使用 `@nuxtjs/i18n`**。语言路由由自建方案处理：

- `app/middleware/locale.global.ts` — URL 规范化
- `app/composables/useLocalePath.ts` — 链接前缀
- `i18n/index.ts` — 语言包加载与切换

## 支持语言

| Locale          | URL              | 持久化方式 |
| --------------- | ---------------- | ---------- |
| `zh-CN`（默认） | 无前缀，`/`      | cookie     |
| `en-US`         | `/en` 前缀       | cookie     |
| 其他支持语言    | `/<prefix>` 前缀 | cookie     |

配置：`config/site.ts` → `SUPPORTED_LOCALES`、`SITE_LOCALE_PREFIX_MAP`

当前内置支持：

`zh-CN`、`en-US`、`pt-PT`、`es-ES`、`ko-KR`、`th-TH`、`ms-MY`、`id-ID`、`ph-PH`、`ja-JP`、`de-DE`、`fr-FR`、`ru-RU`、`zh-HK`、`pt-BR`

## 公开页 vs 产品页

| 区域        | URL 是否随语言变化      | 切换语言时     |
| ----------- | ----------------------- | -------------- |
| 公开 SEO 页 | ✅ `/` ↔ `/en`          | URL 变化       |
| 产品页      | ❌ 始终 `/workspace` 等 | 仅 UI 文案变化 |

`isProductPath()` 判断产品路径，语言切换时不改 URL。

## 文案文件

```
i18n/
├── index.ts                    # loadLocaleMessages、getSwitchLanguageUrl
├── zh-CN/
│   ├── index.ts                # 聚合 modules/*.json
│   └── modules/
│       ├── global.json
│       ├── product.json
│       └── marketing.json
└── en-US/
    ├── index.ts
    └── modules/
```

页面中使用：

```vue
<script setup lang="ts">
const { t } = useI18n()
</script>

<template>
  <h1>{{ t('home.title') }}</h1>
</template>
```

## 新增语言步骤

1. `config/site.ts` — 扩展 `SUPPORTED_LOCALES`、`SITE_LOCALE_PREFIX_MAP`
2. 新建 `i18n/<locale>/modules/*.json` 与 `index.ts`
3. `i18n/index.ts` — 注册 locale message resolver
4. `config/antd-locale.ts` — 补充 Ant Design Vue locale loader（无官方包时明确 fallback）
5. 运行 `pnpm i18n:diff` / `pnpm i18n:scan` / `pnpm i18n:unused` 更新全量、已使用与未使用快照
6. 运行 `pnpm i18n:check` 检查 locale 配置、目录、resolver、AntD 映射、模块 key 冲突与快照同步
7. 更新 `tests/unit/locale-*.test.ts`
8. 验证 hreflang、html lang、sitemap 与 Ant Design Vue locale 映射

## 常用 API

| API                                   | 用途                   |
| ------------------------------------- | ---------------------- |
| `useLocalePath().localePath('/help')` | 当前语言下的路径       |
| `useLanguageSwitch()`                 | 切换语言并 router.push |
| `useI18n()`                           | 翻译函数 `t()`         |

产品壳内（编辑器头、UserAccountMenu）可切换 UI 语言而不改变产品 URL；语言会通过 cookie 持久化，刷新 `/workspace`、`/docs/*`、`/account` 时仍保持上次选择。
