# 主流 Nuxt SaaS 对齐：独立产品路由 + App Shell

> **破坏性重构**：一次性切换到最终路由与架构，**不保留** `/app/**`、`/login`、`/register` 等旧 URL，**不做** 301 兼容层、redirect 别名或双轨配置。旧页面目录与 dead code 直接删除。

## 重构原则

1. **只维护一套路由真相**：`config/routes.ts` + `app/pages/` 文件结构；禁止「旧 helper + 新 helper」并存。
2. **产品区 URL 语言中立**：`/workspace`、`/docs/:id`、`/account` 永不带 `/en` 前缀；`/en/workspace` 等仅作 301 → 无前缀 canonical（i18n 双轨，非历史兼容）。
3. **Canonical 只在一处实现**：`config/routes.ts` 导出算法；`locale.global.ts`（客户端）与 `server/middleware/product-canonical.ts`（SSR 首请求）**调用同一函数**，`auth.ts` **不再** 处理 product canonical。
4. **Nav 单一数据源**：`product-shell/config.ts` 只保留 `productNavItems` / `productFooterNavItems`；删除 `productRouteConfigs`、`getProductRouteConfig`、`ProductRouteMode` 及未消费的 `auth/seo/mode` 字段。
5. **用户入口统一**：产品区与营销页登录态均通过 `UserAccountMenu` + 共享 composable；不在 Sidebar 放账户项。

## 最终路由模型

**`/workspace` 不是产品区统一前缀**，仅覆盖工作台及其子页；编辑器与账户为独立顶级路由。

| 页面       | URL                         | 文件                            | Layout    | 入口                     |
| ---------- | --------------------------- | ------------------------------- | --------- | ------------------------ |
| 工作台     | `/workspace`                | `workspace/index.vue`           | `product` | Sidebar「工作台」        |
| 主题模版   | `/workspace/templates`      | `workspace/templates/index.vue` | `product` | Sidebar「主题模版」      |
| 作品编辑器 | `/docs/:id`                 | `docs/[id].vue`                 | `editor`  | 工作台跳转；无 Sidebar   |
| 账户       | `/account`                  | `account.vue`                   | `product` | 用户菜单                 |
| 登录       | `/sign-in`（`/en/sign-in`） | `[[language]]/sign-in.vue`      | `default` | 营销区 CTA / auth 中间件 |
| 注册       | `/sign-up`（`/en/sign-up`） | `[[language]]/sign-up.vue`      | `default` | 营销区 CTA               |
| 定价       | `/pricing`                  | `[[language]]/pricing.vue`      | `default` | Sidebar footer 外链      |

**行为约定：**

- 登录成功默认进入 **`/workspace`**（无 `redirect` query 时）。
- 工作台 ↔ 主题模版 ↔ 账户：同 `product` layout，Sidebar + 顶栏不 remount。
- 工作台 → 编辑器：`navigateTo('/docs/:id')`，切换 `editor` layout 全屏页。
- 编辑器 → 工作台：返回链 **`/workspace`**。
- **不做**独立 Home；登录后不以账户页为默认落地页。

## `config/routes.ts` 最终形态

产品路径判定与 CSR / canonical **只在此文件定义**，其他模块 import，禁止复制逻辑。

### 常量

```ts
/** 用于 nuxt.config routeRules（CSR）与测试断言 */
export const productRoutePatterns = ['/workspace/**', '/docs/**', '/account'] as const

export const csrRouteRules = [...productRoutePatterns]
```

### `isProductPath(path)`

```ts
export const isProductPath = (path: string): boolean => {
  const p = path.startsWith('/') ? path : `/${path}`

  if (p === '/account') return true
  if (p === '/workspace' || p.startsWith('/workspace/')) return true
  if (p === '/docs' || p.startsWith('/docs/')) return true

  return false
}
```

### `localizedProductPathToCanonical(path)`

**替换**原先 `secondSegment === 'app'` 的特殊逻辑；算法：

```ts
export const localizedProductPathToCanonical = (path: string): string | null => {
  const segments = path.split('/').filter(Boolean)
  const [firstSegment, ...rest] = segments
  const localePrefixes = Object.values(SITE_LOCALE_PREFIX_MAP)

  if (!firstSegment || !localePrefixes.includes(firstSegment)) {
    return null
  }

  const pathWithoutLocale = rest.length ? `/${rest.join('/')}` : '/'

  return isProductPath(pathWithoutLocale) ? pathWithoutLocale : null
}
```

示例：

| 输入                      | 输出                   |
| ------------------------- | ---------------------- |
| `/en/workspace`           | `/workspace`           |
| `/en/workspace/templates` | `/workspace/templates` |
| `/en/docs/new`            | `/docs/new`            |
| `/en/account`             | `/account`             |
| `/workspace`              | `null`                 |
| `/en/pricing`             | `null`                 |

### `localizedPath(path, locale)`

产品路径 **原样返回**，不加重 locale 前缀（逻辑保持不变，依赖新 `isProductPath`）。

## Middleware 职责划分

| 模块                                     | 职责                                                                                                 | 禁止                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `locale.global.ts`                       | 尾斜杠、`/zh` 默认语言、**调用 `localizedProductPathToCanonical` 301**、不支持 locale 404、加载 i18n | 内联 duplicate canonical 逻辑                                          |
| `server/middleware/product-canonical.ts` | SSR 首请求：同上函数 301                                                                             | 额外 product 规则                                                      |
| `auth.ts`                                | `ensureSession` + 未登录 → `/sign-in?redirect=` + RBAC 403                                           | **product canonical 301**（删除 `buildProductCanonicalRedirect` 调用） |
| `definePageMeta({ middleware: 'auth' })` | 产品页与账户页保护                                                                                   | 依赖 `productRouteConfigs`                                             |

`buildProductCanonicalRedirect` 可保留为 **纯函数** 供 locale / server 测试复用，但 **auth middleware 不得 import 或使用**。
